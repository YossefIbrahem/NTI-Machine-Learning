About the model
  • SVR (C = 3) tuned with GridSearchCV, best of 13 regression models compared with 5-fold cross-validation.
  • Test R² = 0.67 on log price, median error ≈ 25 %. Location (compound, city) and size drive the price.
  • The trained scikit-learn model runs entirely in your browser, and its predictions match the Python model exactly.
