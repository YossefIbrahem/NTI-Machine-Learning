About the model
  • Ridge regression in a scikit-learn Pipeline, best of 13 regression models compared with 5-fold cross-validation.
  • Test R² = 0.989, average error ≈ 1.7 points; 94 % of predictions are within ±4 points.
  • Each extra study hour adds ≈ 2.9 points and each previous-score point ≈ 1.0 point; sleep, practice papers and activities add a little.
  • The trained model runs entirely in your browser and gives exactly the same predictions as the Python model.
